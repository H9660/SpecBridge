# How the developers fixed the golden tickets (the answer key)

For each SPEC ticket copied from the OpenMRS Jira: the original O3 ticket, the real fix commits and pull requests on GitHub, and the number of code files they changed. The agent reads the code at the frozen commit *before* these fixes; the eval compares what it finds with these files. Made by `scripts/show_fix.py --all`; for one ticket's file list and diff: `scripts/show_fix.py SPEC-12 --diff`.

The trick tickets (SPEC-64..69) and the edge-case tickets (`test_tickets_v1.json`) were written by hand, so they have no real fix; their expected results are in their JSON files.
